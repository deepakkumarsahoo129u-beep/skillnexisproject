📊 Sales Performance Dashboard (Excel Project)
This project presents an interactive Pivot Table Dashboard built in Microsoft Excel to analyze and visualize sales performance using the Global Superstore 2016 dataset.

🔍 Key Insights
Total Revenue: Displays overall revenue generated across all departments.

Sales by Category: Breaks down sales performance by product categories to identify top-performing segments.

Yearly Sales Trends: Tracks revenue growth and seasonal patterns over multiple years.

Department-wise Revenue: Highlights revenue contribution from each department for strategic comparison.

🧩 Features
Dynamic pivot tables for flexible data exploration.

Interactive charts and slicers for quick filtering and trend analysis.
